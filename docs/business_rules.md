# 业务规则与分析口径

## 库存

- 期初记录为 2026-06-09 00:00:00 的 OPENING，代表该日营业前已有库存，不是本期采购。
- 所有 quantity 为正整数。期末 = OPENING + RECEIPT - ISSUE。不要把期初算两次。
- 账面库存包括冻结与过期货；可出库库存须同时满足质量 RELEASED、到期日大于业务日期、账面结存大于零。
- 到期日当天不可出库，这是本项目明确采用的模拟边界。临期定义：可用批次剩余天数在 1 至商品预警天数之间（含边界）。
- 批次质量状态在整个模拟期固定；HOLD 是已收货但未验收放行。received_qty 已计入账面，但不可发货。expected_qty 是单据预期数量，不参与库存计算。
- 原料保质期由批次到期日决定；商品档案仅存预警参数。生成器可产生后到货先到期的情况，用于区分 FIFO 和 FEFO。
- 一批次固定一货位。库位优化仅是方案比较，未落地为历史移库流水。
- 盘点发生在当日 20:00，晚于发货。差异保留待调查，未审批调账；后续月份账面不会自动跟着实盘变化。

## 周转与成本

- 每日期末包含当日所有业务，统计期90个自然日，即使无流水也要填充当日结存。
- SKU平均库存为90个每日期末库存的算术平均。
- SKU周转次数 = 本期 ISSUE 数量 / 平均库存数量。
- 周转天数 = 90 / 周转次数。零出库标为“期间无出库”，不要除零或假设其周转天数为0。
- 每个SKU使用固定模拟单价，未采用移动加权或FIFO成本层。
- 整体周转次数 = 本期出库成本 / 期间平均库存金额。先每日按SKU结存×单价汇总金额，再取90日平均。
- 不同SKU的袋、瓶、包不能直接相加比较规模；金额可以相加。
- 本项目衡量仓库领用出库，不代表门店销量、毛利或实际消耗。历史出库受缺货限制，需求研究优先看订单申请，不能仅用已发数量替代需求。
- 可自定呆滞规则，例如期末有库存且连续30天无出库，但必须记录阈值。零出库SKU单独处理。

## 订单与发货

- 订单表一行是一条商品需求，一个订单可有多行；一条需求可以分多个批次出库。
- 已发数量需通过order_line_id汇总 ISSUE；缺口 = requested_qty - 已发数量。
- 门店需求10:00录入，14:00按门店编号顺序分配同日可用库存，这是基准策略，不是公平分配最优解。
- actual_ship_time为首次发货时间，部分发货也可能有值，不能据此判断足量。
- 按时足量行率：截止promised_ship_time累计发出数量达到requested_qty的订单行数 / 订单总行数。本数据每行最多一个发货时刻，未发时间为空。
- 订单结束后未发部分视为期末未满足历史需求；不自动递延到次日，不重复创建补单。
- 订货偏高只能标记待确认。不要在尚未调查时自动删单、改数。
- 重新计算建议批次时使用订单时点库存，不能用报告期末库存代替。

## 盘点与巡检

- 差异 = recount_qty - book_qty_snapshot。
- 一致率按盘点行计算，一行是时点＋SKU＋批次＋货位。不同日期盘点不要去重成单个SKU。
- 巡检为定期抽样观察，异常没有事先确认原因。补充调查、责任人和处置建议，不能改原始观察为“已整改”。

## 库位距离实验

- locations中的坐标单位是米；起终点设发货口(0,0)。
- 第一版可定义每条订单明细独立往返货位，距离=2×(|x|+|y|)，整单多点路径留到扩展阶段。此口径不是实际仓库最短路线。
- 基线频次按实际出库的订单明细＋货位计数去重，避免把同货位分批记录重复计为多次拣取。
- 调整在相同zone内进行，检查峰值存量×unit_weight_kg不超max_weight_kg。先做一SKU一货位的交换，不新增货位、不更改订单。
- 前后使用同一批订单、同一路径模型；模拟距离改善不等于真实人工时间或成本改善。
